# LX 手表版

基于 LX Music 移动版 1.9.1 修改的手表适配版本。包名与官方版本不同，可与官方版本同时安装。

| 项目 | 内容 |
| --- | --- |
| 包名 | `cn.dsh.lxmusic.watch` |
| 应用名 | LX 手表版 |
| 上游版本 | [lyswhut/lx-music-mobile](https://github.com/lyswhut/lx-music-mobile) v1.9.1 |
| 适用设备 | 智能手表（屏幕短边约 400 至 540 dp） |

## 安装

从 Releases 页面下载 `LX-Watch-v1.9.1-arm64-v8a.apk`，安装至手表。

运行环境为 Android 6.0 及以上，arm64-v8a 架构。

## 界面

- **导航**：屏幕左侧为常驻导航栏，包含我的列表、搜索、歌单、排行榜、设置五项，点击即切换页面。
- **我的列表**：顶部为列表切换栏，左侧箭头切换上一个列表，右侧箭头切换下一个列表，点击中间区域打开全屏列表选择界面，点击某一项即切换至该列表。
- **歌曲列表**：单行显示序号、歌曲名与歌手名；点击播放，长按打开歌曲菜单。
- **播放页**：封面与歌词分页显示，左右滑动切换；进度条支持点击与拖动定位。

## 尺寸适配

界面尺寸由当前窗口尺寸推导，不采用固定像素值，因此在其他尺寸的表盘上同样适用。

```
主字号   = 短边 × 0.036（限制在 10 至 17 sp，再乘以用户字号倍率）
顶栏高度 = max(屏幕高 × 8.5%, 主字号 × 2.6)
播放条高 = max(屏幕高 × 15%,  主字号 × 4.6)
列表行高 = max(屏幕高 × 10.5%, 主字号 × 3.6)
左右留白 = 屏幕宽 × 8.5%
封面边长 = min(短边 × 42%, 剩余高度 × 60%)
```

顶栏、播放条与一行歌曲合计约占屏幕高度的 34%，各字号档位下均不会溢出。

## 其他调整

- **圆角与系统栏避让**：左右留白按屏幕宽度比例计算；上下留白可在设置中调整；状态栏高度取自系统接口，避免被第三方系统遮挡。
- **文字行高**：手表端显式设置行高，解决中文下半部分被裁切的问题。
- **字号档位**：设置中提供六档字号，修改后立即生效。
- **界面形态**：可在设置中选择自动识别、手机版界面或手表版界面；自动识别依据屏幕尺寸判断。
- **音源导入**：设置 → 源 → 从 Download 目录导入音源，直接扫描存储目录中的脚本文件。
- **更新检查**：因包名与版本号均与官方版本不同，更新检查已关闭。

## 保留功能

歌曲菜单、列表菜单、歌词字号与对齐、桌面歌词、定时停止播放、播放器设置、评论页等，均沿用上游实现，未作修改。

## 构建

环境要求：Android SDK、JDK 17、Node.js 18 及以上版本。

```bash
npm install
cd android
./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
```

构建产物位于 `android/app/build/outputs/apk/release/`。

签名相关文件（`*.keystore`、`keystore.properties`）未包含在仓库中，需自行生成。

适配过程的详细记录见 [doc/开发记录.md](doc/开发记录.md)。
